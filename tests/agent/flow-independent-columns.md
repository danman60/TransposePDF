# Independent editor columns

1. Open TransposePDF and create a chart with four labeled sections. Make the first section one lyric line, the second section at least six lyric lines, and the remaining sections one lyric line each.
2. Save the chart, choose two columns, and confirm sections flow vertically within each column without a large blank row caused by the tall section beside a short section.
3. Confirm every section remains visually contained in one column with no overlap or horizontal scrollbar.
4. Edit a lyric and drag a chord in the two-column chart. Confirm both changes remain editable and persist after reload.
5. Switch to a narrow mobile viewport. Confirm chart displays as one column.
