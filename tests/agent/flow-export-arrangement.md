# Visible export and arrangement follow-along

1. Open a saved chart in editing mode. Confirm Export PDF is visible in the left song-tools sidebar without scrolling.
2. Activate Export PDF and confirm the PDF export controls open.
3. Return to the chart and scroll to Arrangement. Confirm it is a large, prominent, wrapping follow-along field rather than a single metadata line.
4. Replace Arrangement with `I V1 C V2 C B C`, reload, and confirm exact manual text persists.
5. Confirm lyrics remain editable and a chord can still be dragged after the UI changes.
